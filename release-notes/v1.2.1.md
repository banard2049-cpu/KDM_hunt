# v1.2.1 第二屏幕地址显示在左侧栏

## 第二屏幕

- 「第二屏幕」打开后，第二屏幕地址（`http://<局域网IP>:<端口>/d/`）会直接显示在左侧栏「第二屏幕控制」里战斗信息（如 `屠夫 · Butcher · Level 1 · 随机地形 1 张`）的**下方**，平板／电视的浏览器照着输入即可，不必再去复制链接。
- 显示的是**其他设备该输入的局域网地址**，不是主控窗口自己用的回环地址；设备有多张网卡（Wi-Fi 与虚拟网卡等）时逐条列出，点一下即可整条选中复制。
- 「停止第二屏幕」后地址随分享一起消失；刷新页面时若分享仍在，地址照常显示。
- 该行只显示地址本身，不附带任何说明文字。
- 修正 v1.2.0 说明中的一处错误：分享界面并**不**显示二维码，只显示上述地址。

## 说明

- 第二屏幕其余行为（只读快照、固定短地址 `/d/`、旧长地址 `/display/<token>/`、尺寸与视图开关、断线重连）与 v1.2.0 一致。
- `npm test` 的决战检查同步更新：断言地址行的位置、内容与显隐时机（开启显示、停止隐藏、显示局域网地址而非回环地址），并确认界面不绘制二维码。
