# v1.2.2 修复安卓版第二屏幕空白页

- 修复安卓版点击「第二屏幕」后打开空白页的问题：在应用内开启分享，并定位到「第二屏幕控制」中的局域网地址。
- 修复原生分享插件的调用方式，使用 Android 注入的插件接口启动服务和同步战斗。
- 分享成功后只显示地址，删除「在同一局域网的设备浏览器中输入上方地址」提示。
- 开启期间显示启动状态，失败时显示原因并允许重试；连续点击不会重复启动服务。
- 电脑端继续在独立窗口显示第二屏幕。

已通过 `npm test`，新增 Android 插件调用、地址显示、连续点击、停止及失败重试的回归检查。

公开 APK 使用普通清晰度资源，沿用既有开发签名。
