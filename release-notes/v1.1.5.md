# v1.1.5 详细调试版本

## 🔍 改进

- **增强调试输出**：战利品加载时会在控制台输出详细的调试信息
  - 显示尝试的每个路径
  - 显示 HTTP 响应状态和 Content-Type
  - 显示响应大小
  - 帮助诊断 GitHub Release APK 的 404 问题

- **修复构建流程**：修复了 GitHub Actions 中的脚本错误

## 🐛 已知问题

- GitHub Release 构建的 APK 中战利品页面可能显示 404（本地构建正常）
- 本版本增加了详细日志，可以用浏览器开发者工具查看控制台输出

## 📝 测试说明

如果遇到战利品加载问题：
1. 在 Android 设备上启用 Chrome 调试（设置 > 开发者选项 > USB 调试）
2. 用 Chrome 访问 `chrome://inspect` 查看 WebView 日志
3. 或者将设备连接到电脑，使用 `adb logcat` 查看日志

## 📦 下载

直接安装 APK 文件即可，无需联网。
