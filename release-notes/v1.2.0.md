# v1.2.0 决战布场与第二屏幕

## 决战布场

- 新增「决战」（Showdown）布场模块，资料来自 TTS 模组归档：**45 个 Boss／变体、137 个等级、21 个地形扩展、63 张地形卡**。
- 每个等级按规则拆出**固定地形**、**指定地形**与**随机地形数量**，抽取时先取出规则指定的地形，再从随机牌池补齐，不会少发或重复。
- 「随机地形池」默认只含基础牌库，可按扩展分组勾选、按地形名搜索，单张地形也可单独勾选；「只留基础／全选／全不选」一键调整。
- 粉丝扩地形默认不进入牌池，仅在左侧勾选「显示粉丝扩地形」后加入；当所选等级的规则本身需要该地形时会自动带入，否则粉丝扩等级无法布场。
- 支持重抽地形、逐格替换随机地形、应用地形；固定的与指定的地形始终按规则保留。
- 牌池不足时明确报错并提示需要在随机地形池里多勾几张，不会静默少发。
- 布场结果随战斗存档保存，恢复旧战斗或旧存档时结果一并还原。

## 第二屏幕

- 新增页首「第二屏幕」按钮：把布场结果推送到同一局域网内的平板／电视／电脑上**只读**显示，供桌面摆场时对照。
- 第二屏幕地址固定为 `http://<局域网IP>:<端口>/d/`，并显示二维码；旧的长地址 `/display/<token>/` 仍然有效，先前打开的窗口不会失效。
- 主控端可随时调整：版图大小、卡牌大小、重置大小、显示／隐藏初始位置、交换版图与卡牌、旋转卡牌区、对齐方式（居中 → 靠上 → 靠下），以及切换显示**决战版图**或**该等级的 Boss 规则书**。
- 第二屏幕在屏幕旋转、窗口缩放或连接说明文字换行后会重新适配版图，连接中断时保留当前布场并自动重连。
- 分享只提供只读快照，**不暴露任何控制接口**；主控写入接口仅限本机回环访问，资源路径经过校验，无法读取存档、脚本或打包资源以外的文件。
- Android 端新增原生 `ShowdownHost` 插件，无需 Python 后端即可在手机上开启第二屏幕，分享期间保持屏幕常亮；未连接到 Wi-Fi 或热点时给出明确提示。
