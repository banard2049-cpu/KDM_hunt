# KDM狩猎辅助 v1.1.0 - 战利品载入修复版

## 🐛 重要修复

### Android APK 战利品载入失败

**问题**：在 v1.0.5 及之前版本中，Android APK 安装后点击"战利品"按钮会显示错误：
```
战利品载入失败：牌库文件载入失败。原存档未修改。
```

**原因**：Android 构建工具默认压缩 assets 中的 JSON 文件，导致 734KB 的 `loot.json` 无法被 WebView 正确读取。

**解决方案**：
- 在 Android 构建配置中添加 `noCompress 'json'`，防止 JSON 文件压缩
- 增强前端文件加载逻辑，尝试多个路径以提高兼容性
- 在 CI 工作流中自动应用此修复

**影响范围**：所有使用 v1.0.5 及更早版本 APK 的用户

## ✨ 改进

- **更好的错误提示**：当文件加载失败时，会显示具体的错误原因（HTTP 状态码或错误信息）
- **自动化构建**：GitHub Actions 现在会自动应用 Android 资产压缩修复，无需手动干预

## 📦 升级说明

### 从 v1.0.5 升级

由于 v1.0.3 之后的版本使用相同的签名证书，可以**直接覆盖安装**此 APK。

1. 下载新版 APK
2. 点击安装（系统会提示覆盖现有应用）
3. 打开应用，点击"战利品"按钮验证修复

### 从 v1.0.2 或更早版本升级

需要先卸载旧版本，再安装新版本（签名证书不同）。

**⚠️ 重要**：在卸载前，请导出狩猎存档和战利品记录：
- 在狩猎页面点击"导出 JSON"
- 在战利品页面点击"导出战利品记录"

卸载并重新安装后，可以通过导入功能恢复数据。

## 📖 功能概览

### 狩猎系统
- 支持狩猎牌库、随机事件和 Boss 遭遇
- 自动记录狩猎历史和调位
- 支持采集资源（草药、矿石、天空垂钓）
- 离线使用，数据保存在本地

### 战利品系统
- 支持 45 个 Boss/变体，136 个独立等级
- 包含本体、赌博者宝箱、千宰屠夫、官方和粉丝扩展
- 自动结算战后奖励（支持条件判断和奖励骰）
- 卡牌实例管理（可查看、放大、弃置和撤销）
- 支持补抽和指定拿牌
- 高清规则书原图显示
