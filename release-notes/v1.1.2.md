# KDM狩猎辅助 v1.1.2 - CI 测试脚本修复

## 🐛 修复 v1.1.1 的 CI 失败

### 问题
v1.1.1 的 CI 构建失败，原因是测试脚本在 `.maintenance/` 目录中，而该目录被 `.gitignore` 忽略，导致 CI 环境中找不到测试文件。

### 根本原因
在提交 `409191c` 中，测试脚本被移动到 `.maintenance/scripts/` 并添加到 gitignore：
```
Move development and maintenance files to .maintenance/
- Add .maintenance/ and .claude/ to .gitignore
```

这导致：
1. 测试脚本不会被提交到 Git 仓库
2. CI 执行 `npm test` 时找不到文件
3. 构建失败：`ENOENT: no such file or directory`

### 本版本修复

#### 恢复测试脚本到 scripts/ 目录
将关键的功能测试脚本从 `.maintenance/scripts/` 复制回 `scripts/` 目录：
- `check-forest-gate.cjs` - 森林之门功能测试
- `check-flower-start.cjs` - 花骑士起始配置测试
- `check-fan-decks.cjs` - 粉丝牌库功能测试

这些文件现在会被正常提交到仓库，CI 可以正常运行测试。

#### 更新 package.json
```json
"test": "node scripts/check-forest-gate.cjs && node scripts/check-flower-start.cjs && node scripts/check-fan-decks.cjs && echo 'All hunt feature checks passed'"
```
