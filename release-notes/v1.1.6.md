# v1.1.6 资源管理优化版本

## 🚀 重大改进

- **轻量化仓库**：所有游戏资源（~483MB）已移出 Git 仓库
  - 仓库大小显著减小，克隆和推送更快
  - 游戏资源通过 GitHub Release 分发

- **自动化资源管理**：
  - CI 构建时自动从 Release 下载资源
  - 添加资源打包和下载脚本
  - 完整的资源管理文档

- **隐私保护**：
  - 高清（HD）资源保持私有，不上传到任何地方
  - 多层保护确保私有资源不会意外泄露

## 📦 技术改进

- 优化构建流程，减少网络传输
- 改进 .gitignore 规则
- 新增资源管理脚本：
  - `scripts/pack-assets.cjs` - 打包公开资源
  - `scripts/download-assets.cjs` - 下载资源

## 📝 文档

- 新增 `docs/ASSETS_MANAGEMENT.md` - 完整的资源管理指南
- 详细说明本地开发和 CI 构建流程

## 🎯 用户体验

- APK 功能完全一致，包含所有标准分辨率资源
- 无需联网，离线使用
- 安装包大小保持不变

## 📦 下载

直接安装 APK 文件即可使用。
