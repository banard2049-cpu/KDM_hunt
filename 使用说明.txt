KDM 自动狩猎工具（狩猎纯净版）
================================
本包包含狩猎和 Boss 战利品功能。图片与牌库随包提供，可离线使用。无 exe，电脑版需要 Python 3.10+ 运行。

Windows：
  1. 双击 start.bat；
  2. 稍候浏览器会自动打开狩猎面板；
  3. 服务运行期间请保持黑色窗口开启，关闭窗口即停止。

macOS：
  1. 双击 KDM-Hunt.command；
  2. 若系统提示”无权限”，请打开”终端”并执行一次：
       chmod +x KDM-Hunt.command
     然后再次双击；
  3. 稍候浏览器会自动打开狩猎面板，按 Ctrl+C 停止。

Android：
  - 安装提供的 APK 文件后，首次启动可能需要几秒钟加载数据。
  - 所有功能（狩猎、战利品）均支持完全离线使用。

没有 Python 时：
  - Windows：到 python.org 安装 Python 3.10+，安装时勾选
    “Add python.exe to PATH”（start.bat 也支持 py -3 与内置 runtime\python.exe）；
  - macOS：到 python.org 安装 Python 3，或安装 Xcode 命令行工具；
  - 也可把对应平台的 python 放入本目录 runtime\ 子文件夹（python.exe / python3）。

说明：
  - 狩猎遭遇自动进入战利品页，选好 Boss 与具体等级。获胜后点击”抽取战后奖励”。
  - 非狩猎 Boss 可在”战利品”页按扩展、Boss 和等级选择，点击”开始新战斗”。
  - 卡牌可点击放大、逐张弃置。弃牌留在本场弃牌区，不能再抽到；其他同名卡不受影响。
  - “撤销”可撤回最近操作。领取战后奖励后，撤销弃置不会重置领取状态。
  - 补抽、指定拿牌和战后奖励共用剩余牌库；不足时不会自动洗回。新战斗才建立独立牌库。
  - 页面切换、刷新和清理狩猎不会删除战利品记录，可从”已有战斗记录”恢复。
  - 清晰度”高”使用随包的本体 Boss 高清规则书原图；自动奖励仍按 TTS 模组，版本差异会标出。
  - 年老大师、Young Lion 等资料不足处会说明原因；可查看规则图片并手动拿牌。
  - 战利品自动保存在当前浏览器内；”导出战利品记录”导出所有战斗，狩猎”导出 JSON”包含关联战斗。
  - 电脑版服务器还会在 saves\ 保存狩猎副本。请导出备份后再清理浏览器数据或卸载应用。
